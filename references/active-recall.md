# 主动检索与作答诊断

仅在用户要求课程自测、暂不提供答案或批改作答时读取。目标是让用户通过回忆、解释和迁移暴露理解缺口，不以生成更多题目代替学习；不承诺短期精通。

## 确定范围与出题

- 复用用户指定的课程、章节、已有知识地图与相关来源。范围不明确且无法从上下文确定时才询问，不顺带考查整库。已有出题和答案要求优先。
- 按概念依赖选择有区分度的问题，覆盖核心概念、因果关系、应用和适用条件；存在真实争议时才加入观点与证据比较。题量随范围及用户要求调整，不设固定题数配额，也不让所有题只考同一条公式。
- 出题前核对条件、可解性和评价依据。需要计算或运行代码时实际验证；开放题准备合理的评价维度，不伪造唯一标准答案。引用或改编题标注出处，原创题如实标注；若来源标题会泄题，首次仅注明来源类型，批改时补全可追溯引用。
- 在对话中只展示题干、必要数据与作答方式，邀请用户暂时合上材料，用自己的话写出理由、过程和不确定处。不能声称已确认用户真的闭卷，不要求安装监控或其他工具。
- 不在同一轮附上答案，包括折叠 callout、反向文字、可直接跳到解答的链接或提前泄露结论的提示。用户请求提示时，从澄清问题、提示相关原理到关键步骤逐级提供，并标明使用了提示；用户直接要求答案时可给出，不强迫继续测试。
- 出题后等待实际作答；不要模拟用户答案、替用户完成测试或先行宣布学习结果。仅请求自测时默认不写文件；用户明确要求保存无答案试卷时才保存，也不在试卷附件中藏入解答。

## 根据实际回答诊断

逐题对照题意、相关笔记与原始依据，按需说明：

1. **已经体现的理解**：指出回答中具体正确的推理或步骤，而不只说“很好”。
2. **关键遗漏或错误**：区分概念混淆、因果链缺失、假设误用、计算失误与表达不清；引用用户实际作答的位置，不为每题机械贴满标签。
3. **为什么影响结论**：说明错误怎样导致当前结果，以及纠正它所需的最小解释或反例。关键订正给出可回查的章节、页码或笔记位置；参考答案也可能有错，不能只按文字相似度判分。
4. **下一步验证**：给一个针对同一缺口、但改变条件或情境的小问题，检验能否迁移；在用户再次作答前不揭示该再测题答案。

部分作答只批改已答部分，未答标为未作答，不能据此推断不会。表达歧义时先追问，证据不足时承认无法判定。若发现题目有歧义、条件不足或原参考答案错误，先修正题目与评价，不把出题错误算成用户错误。

按用户需求给分；使用分数时交代评价依据，不用无依据的精确百分比表示“掌握程度”。反馈聚焦可观察表现，如“能套用公式，但还未说明成立条件”；单次答对或看过解析不代表独立、稳定地掌握。

## 定向补缺与写回

- 从本轮回答中提炼少量最关键的缺口，指向已有笔记的对应段落，解释“需要补什么、为什么、怎样再验证”；避免每次都建议从头重学或自动扩展整门课程。
- 同一问题反复出现时调整讲解、例子或难度，不原样重复出题；用户已完成本轮要求或希望结束就收束，不无限追问。
- 默认在对话中反馈。用户要求记录错题或学习进度时，按库内规则保存到已有相应位置，记录实际题目、作答、诊断与再测情况；不复制整篇知识正文，不把未经作答的练习标成已完成。
- 若批改发现既有笔记可能有错，指出证据与具体位置。普通批改不授权重写旧笔记；得到修订授权后才按备份、局部修改和更新记录流程处理。
